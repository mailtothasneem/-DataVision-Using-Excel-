-DataVision-Using-Excel-
 
This repository contains assignments focused on data analysis using Excel formulas like SUM,AVERAGE and conditional formatting.


Description

This project demonstrates how to perform data analysis using Excel. It covers topics such as data preprocessing, exploration, and visualization using formulas like SUM, AVERAGE, conditional formatting.

Getting Started
 Dependencies
 Prerequisites

Before using this project, make sure you have:

- Operating System: Windows 10 or later (works best on Windows 11 too)
- Microsoft Excel : Version 2016 or newer (Excel Online or Google Sheets can also be used)
- Optional Libraries/Tools:
- Power Query (for advanced data preprocessing in Excel)
- Pivot Tables enabled
- Internet Access: Required if using OneDrive or Google Sheets
 

Installing
No installation required — simply download the Excel files from this repository.

Executing Program
1. Open the Excel file `Excel Assignment 1 - Data Exploration.xlsx`.
2. Follow the instructions in the sheet tabs.
3. Use formulas and pivot tables to explore the dataset.
